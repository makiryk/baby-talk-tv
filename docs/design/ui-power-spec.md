## 1. 画面表示仕様（赤ちゃん視覚保護 ＆ OLED保護）

### 1.1 基本方針
- **視覚刺激の完全排除**: 赤ちゃんがテレビ画面を注視・凝視するのを防ぐため、文字やキャラクター、派手なアニメーションは一切表示しない。
- **純黒背景**: 背景色は完全な黒 `#000000`。
- **輝度制御**:
  - ウィンドウ属性でバックライトを最小化（`layoutParams.screenBrightness = 0.05f`）。
  - ※ 0.01f だと暗い部屋で動作インジケーターすら見えなくなる懸念があるため、実機視認性を確保できる 0.05f を基準とし、設定画面で調整可能とする (L1対応)。

### 1.2 動作状態インジケーター
親が「アプリが正常に動いているか」を一目で把握できるよう、画面の隅（マージン 32dp）に極小サークル（直径 14dp）を1つだけ表示します。

| 状態 | 色 / アルファ | 演出・アニメーション | 備考 |
|---|---|---|---|
| **待機中（見守り中）** | `#555555` (暗灰色) | 呼吸のようなゆっくりとしたパルス明滅（周期 4秒、アルファ 0.3〜0.6） | 暗所でも親が視認可能 |
| **聞き取り中（声検知）** | `#4A90E2` (淡いブルー) | ふわりと点灯（アルファ 0.8） | **発話中（SPEAKING）は絶対に点灯しない (H3受入基準)** |
| **発話中（語りかけ中）** | `#7ED321` (淡いグリーン) | やわらかな発光（アルファ 0.8） | 音声再生中のみ点灯 |

### 1.3 有機EL（OLED）焼き付き防止（ピクセルシフト）(L2対応)
- 固定位置での長時間点灯を防ぐため、60秒ごとにインジケーターの座標を現在位置から微小（±8〜16dp）にランダム移動させます。

## 2. タイマー設定仕様

### 2.1 タイマー値と安全上限 (L3対応)
- 選択肢: **5分 / 10分（デフォルト） / 15分 / 30分 / 60分 / 最大120分**
- ※「無制限」は夜通し稼働・API過剰消費・OLED焼き付きのリスクがあるため廃止し、最長「120分」を安全上限とします。

### 2.2 設定インターフェース（誤操作防止 ＆ 赤ちゃんに見せない配慮）(L4対応)
- **誤操作防止**: 赤ちゃんがリモコンをいじって設定画面が開かないよう、単押しではなく**「十字キー（上または下）の1秒長押し」**または**「アプリ起動直後の5秒間」**のみ設定UIを受け付けます。
- **UI表示**:
  - 画面中央に低輝度グレー（`#666666`）で、「タイマー: 10分」と小さく表示。
  - 上下キーで時間変更、OKキーまたは5秒放置で設定確定。
- **自動フェードアウト**:
  - 確定後、文字は直ちにフェードアウトし、完全な黒画面（インジケーターのみ）へ戻ります。

## 3. タイマー終了・テレビ電源制御（ベストエフォート ＆ 安全消灯）(H1, H2対応)

### 3.1 現実的なTV電源制御の前提 (H1対応)
- Android TVプラットフォーム（メーカーOS、Google TV、Chromecast等）において、サードパーティ製アプリから物理的なテレビ本体の主電源を100%確実にOFFにすることは仕様上保証されていません（`PowerManager.goToSleep()` 等はシステム署名が必要、HDMI-CEC連動は機種の実装依存）。
- したがって、要件定義における電源制御は**「ベストエフォートによるスタンバイ試行 ＋ 確実な完全黒画面・消音による消灯状態担保」**と位置づけます。

### 3.2 終了シーケンス
```
[タイマー満了]
      │
      ▼
[終了フェーズ突入]
   - マイク録音即時停止（赤ちゃんの声遮断）
   - 終了挨拶フレーズを発話（例: 「今日はいっぱいお話ししたね、おやすみなさい」）
      │
      ▼ (タイムアウト付き発話完了待機: 最大15秒)
[発話完了]
      │
      ▼
[1. スタンバイ試行 (ベストエフォート)]
   - TvPowerAccessibilityService.performGlobalAction(GLOBAL_ACTION_LOCK_SCREEN) を実行。
   - OSがスタンバイに移行し、HDMI-CEC連動でTV画面が消灯する環境では物理電源がOFFになる。
      │
      ▼
[2. 安全消灯フォールバック (H2対応 - 重要)]
   - ※ ホーム画面には戻さない（派手なコンテンツや動画プレビューが自動再生され、赤ちゃんを刺激するため）。
   - 純黒画面（#000000）を維持し、インジケーターも完全消灯（アルファ 0）。
   - `FLAG_KEEP_SCREEN_ON` を解除し、OS標準のスリープタイマーへ引き渡す。
   - すべての音声再生・バックグラウンド処理を停止。
```

### 3.3 AccessibilityService 最小権限設計 (M8対応)
- Google Playポリシーおよびセキュリティに配慮し、不要なイベント購読（`typeAllMask`）は一切行わず、`canPerformGlobalActions` のみを宣言します。
```xml
<accessibility-service xmlns:android="http://schemas.android.com/apk/res/android"
    android:canPerformGlobalActions="true"
    android:description="@string/accessibility_service_desc" />
```
- メモリリーク防止のため、サービスインスタンスの長期保持は行わず、WeakReferenceまたはBroadcast経由で呼び出します。
